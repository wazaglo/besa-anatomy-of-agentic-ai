# CustomerSupport Agent

Strands-based customer support agent for Amazon Bedrock AgentCore.

## Quick Start

```bash
# Local development
agentcore dev

# Deploy to AWS
agentcore deploy
```

## Tools

| Tool | Description |
|---|---|
| `get_return_policy` | Return policy lookup by product category |
| `get_product_info` | Product search by name, ID, or keyword |
| `check_warranty` | Warranty status via Gateway Lambda (Lab 3+) |
| `process_refund` | Refund processing via Gateway Lambda (Lab 7+) |
| Exa AI MCP | Web search for product information |
